# Star Generation — Student & Tutor App (PWA)

Mobile-first, installable web app.

**Students:**
- browse and enroll in group classes
- pay package invoices (simulated)
- see the schedule, approved logbooks and hours left
- buy a new package when running low

**Tutors:**
- schedule lessons (WIB) and cancel them
- write one logbook entry per lesson, then submit the month
- fix logbooks the admin sends back
- see earnings per lesson and month, approved vs pending

> Setup, seeded logins, architecture and decisions live in the API repo: **[sg-api](https://github.com/dimsurd/sg-api)**.
> The admin back office is **[sg-backoffice](https://github.com/dimsurd/sg-backoffice)**.

## Run

The API must be running on `http://localhost:4000` (see sg-api's README).

```bash
pnpm install
pnpm dev            # http://localhost:3000
```

Sign in as `student1@stargeneration.test`, `student2@…` or `tutor1@…`; the password is `Password123!`. The login screen has one-tap shortcuts for these.

To try the PWA itself (install prompt, offline page), run a production build: `pnpm build && pnpm start`. The service worker isn't registered in dev.

| Script | |
|---|---|
| `pnpm dev` / `pnpm build` / `pnpm start` | Next.js on port 3000 |
| `pnpm typecheck`, `pnpm lint` | Static checks |
| `pnpm gen:api` | Regenerate `src/lib/api/schema.d.ts` from the running API's `openapi.yaml` |

## PWA

- `src/app/manifest.ts`: name, theme colours, and icons generated by `src/app/pwa-icon/[size]/route.tsx`
- `public/sw.js`:
  - cache-first for hashed static assets
  - network-first for pages, with an `/offline` fallback
  - **never caches `/api`**, so balances and invoices are always live; cached pages are cleared on logout
- Offline banner driven by React Query's online state; queries resume automatically on reconnect.
- **Install button** (home-screen card + account menu, `src/components/install-app.tsx`):
  - Chromium (Android, desktop Chrome/Edge): opens the native install dialog via `beforeinstallprompt`
  - iOS/iPadOS: there is no install API, so it shows a Share → Add to Home Screen guide
  - Hidden once the app is installed. "Not now" is remembered for 14 days.

## Layout

```
src/
  app/student/        my classes, browse, invoices, class (schedule + logbooks)
  app/tutor/          teaching home, class (schedule/cancel), logbooks, earnings
  app/login, offline  sign-in and offline fallback
  components/         mobile shell (bottom nav), ui-kit, dialogs, shadcn ui
  lib/api/            typed API client + generated schema
  proxy.ts            routes tutors to /tutor and students to /student (the API still checks every call)
```
